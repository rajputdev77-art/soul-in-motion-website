Create a completion

Send a prompt to a model and receive a single non-streaming response. Returns the full token sequence and a usage object you can charge back. Use /completions/stream for token-level streaming over SSE.

Body application/json
FieldTypeDescription
model required string Model id, e.g. axon-mini-v3. List options via GET /models.
prompt required string Input text. Max 128k tokens (model-dependent). UTF-8 only.
max_tokens integer Hard cap on completion length. Defaults to 1024.
temperature float Sampling temperature, 0.0 â€“ 2.0. Defaults to 0.7.
stop string[] Up to 4 stop sequences. The model halts before emitting any of these.
