01Get your three keys

Before you touch n8n, gather these three things. Save them in a notes file.

1A — Anthropic API Key

  1. Go to console.anthropic.com and sign in.
  2. Click API Keys in the left menu.
  3. Click the Create Key button. Name it "n8n content kit".
  4. Copy the key (starts with sk-ant-) and paste into your notes.

1B — Telegram Bot Token

  1. Open Telegram. Search for @BotFather. Open the chat.
  2. Send /newbot. BotFather will ask for a name, then a username (must end in bot).
  3. BotFather replies with your access token — a long string like 123456789:ABCdef.... Copy it.
Screenshot Placeholder · 01B

1C — Your Telegram Chat ID

  1. Open the chat with your new bot. Send any message (say "hi").
  2. In a browser, open: https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates (replace <YOUR_TOKEN>).
  3. Find the number after "chat":{"id":. That is your chat ID. Copy it.

02Install n8n

Pick one path. The cloud version is fastest.

Path A — n8n Cloud (zero installation)

  1. Go to n8n.io/cloud. Click Get started free.
  2. Sign up with your email. Confirm. You will land in the editor.

Path B — Local install (free forever)

  1. Install Node.js LTS from nodejs.org. Click Next on every screen.
  2. Open Terminal (Mac) or Command Prompt (Windows). Type npx n8n and press Enter.
  3. Wait for the line Editor is now accessible via: http://localhost:5678.
  4. Open that URL in your browser. Create your local account.

03Import the workflow

  1. In the n8n sidebar, click Workflows.
  2. Click the + Add workflow button (top right). An empty canvas opens.
  3. Click the three-dot menu in the top-right corner of the canvas → Import from File.
  4. Select the workflow.json file from this download.
  5. The full 8-node workflow appears, with the Telegram trigger on the left and three Send Message nodes on the right.

04Connect your credentials

Right after import, every node will show a red error icon. That is expected — they need your keys.

4A — Anthropic credential

  1. Click any node titled Claude — Instagram Caption (or any of the three Claude nodes).
  2. In the right panel, find Credential to connect with → click Create New.
  3. Paste your Anthropic key into the API Key field. Click Save.
  4. Open the other two Claude nodes and select the same credential from the dropdown — no need to recreate it.

4B — Telegram credential

  1. Click the Telegram Trigger node.
  2. In the right panel, click Create New credential.
  3. Paste your bot token into the Access Token field. Click Save.
  4. Click each of the three Telegram — Send … nodes and select the same credential.

4C — Set Chat ID in each Send node

  1. For each of the three Telegram — Send … nodes, find the Chat ID field.
  2. The expression {{ $('Extract Blog Text').item.json.chatId }} should already be filled in. Leave it. The chat ID is taken automatically from whoever messages the bot.
Pro tip: Leave Chat ID dynamic (as the expression above) so you can let other people use the bot too. Hard-code your numeric chat ID only if you want a private system that ignores everyone else.

05Activate and test

  1. In the top-right of the workflow canvas, flip the Active toggle to ON. It turns green.
  2. Open Telegram. Open the chat with your bot.
  3. Paste any blog post (a few paragraphs is fine). Press send.
  4. Wait 10–30 seconds. You should receive three messages: Instagram caption, LinkedIn post, 5 YouTube Shorts ideas.

06If something breaks

  • Nothing happens when I send a message: Confirm the workflow is Active. Re-paste the Telegram token.
  • "Invalid API Key" error: Re-paste the Anthropic key. Confirm there is credit on your account.
  • One of the three replies is missing: Click the node with a red badge. Read the error. Most often, the input was too long — keep blog posts under ~3000 words.
  • Output is cut off mid-sentence: Open the relevant Claude node → Options → raise Max Tokens to 2000.
  • "Node type unknown" on import: Update n8n. For local: stop and run npx n8n@latest. For Cloud: it auto-updates.
