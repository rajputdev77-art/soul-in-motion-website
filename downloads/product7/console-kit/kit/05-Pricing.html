Common questions

Three sentences each. If we lied, write to honesty@axon.run.

What counts as a "request"?
Every successful call (2xx) to any inference endpoint — completions, embeddings, rerank, streaming. Errors and rate-limited 429s don't count. Listing endpoints (GET /models, /usage, /keys) don't count either.
Can I cap spend per key?
Yes. Every key has a hard ceiling, a soft warning, and a daily budget. Webhooks fire on each threshold; requests over the ceiling return 402 Payment Required with a clear error body.
What's the difference between Team and Scale?
Team is self-serve and runs on shared infrastructure in iad-1. Scale gets a dedicated region, an SLA, SSO/SCIM, the SOC2 II report, and a named CSM. Most companies switch when they need to pass a security review.
Do you charge for failed requests?
Never. 4xx and 5xx responses are free. If we time out before forwarding to the model, you pay nothing.
Can I migrate off?
Yes. axon is API-compatible with OpenAI's interface — change the base URL and you're back. Export your logs as CSV or Parquet from any plan.
How is "Team" priced annually?
$79/month if paid up front for the year, $99/month if paid monthly. Annual saves you $240/year and locks the included-volume tier for 12 months.
